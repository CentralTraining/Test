Bản này bắt đầu với dữ liệu riêng. Không cần chỉnh Dashboard đang sử dụng. Người nhận dùng tài khoản GitHub của họ, project Supabase mới của họ và ứng dụng/Sandbox TikTok riêng của họ. 02

Tạo repository GitHub và xác định link riêng

  1. Đăng nhập github.com/new.
  2. Đặt tên repository, ví dụ TrainerHub; chọn Public và bật Add a README file. Chọn Create repository.
  3. Link ứng dụng sẽ có dạng https://TEN-GITHUB.github.io/TrainerHub/. Đây là ví dụ đường dẫn sau triển khai, không phải một website đã được tạo sẵn.
  4. Ghi lại link chính xác, gồm chữ hoa/thường của tên repository và dấu / cuối. Bước dưới dùng link này cho APP_URL.

Repository public chỉ chứa mã giao diện và các thông tin công khai của ứng dụng. Tài khoản và số liệu được lưu trong Supabase mới, qua máy chủ có kiểm tra đăng nhập.

03

Tạo Supabase mới và tạo bảng

  1. Vào supabase.com/dashboard → New project. Tạo project mới, chọn vùng phù hợp và lưu mật khẩu database riêng. Chờ project sẵn sàng.
  2. Trong cửa sổ Connect hoặc Project Settings → Data API / API Keys, lấy Project URL và Publishable key. Nếu project cũ dùng định dạng legacy thì dùng anon public key. Không lấy service_role/secret key cho HTML.
  3. Mở SQL Editor → New query. Dán toàn bộ SQL dưới đây, bấm Run.
  4. Trong Table Editor, kiểm tra có trainer_hub_settings và trainer_hub_private. Bảng settings có hai dòng auth_users và config.
  5. Giữ Data API bật và schema public được expose. Nếu đổi cấu hình Data API, máy chủ cần truy cập hai bảng này bằng service role. SQL đã bật RLS và chặn quyền đọc/ghi trực tiếp của trình duyệt.

04

Đặt Secrets và triển khai máy chủ

4.1 — Thêm cấu hình trong Supabase

Mở Edge Functions → Secrets, thêm các tên sau:

Tên SecretGiá trị

TIKTOK_SANDBOX2_CLIENT_KEYTùy chọn: Client Key của Sandbox thứ hai của bản độc lập.

Supabase tự cung cấp SUPABASE_URL và SUPABASE_SERVICE_ROLE_KEY cho Edge Function. Không cần điền lại hai biến này và không chép chúng vào file HTML.

4.2 — Deploy bằng trình duyệt

  1. Mở Edge Functions → Deploy a new function → Via Editor (tên nút có thể là Deploy new function).
  2. Đặt tên function chính xác là trainer-hub.
  3. Xóa source mẫu trong editor. Bấm nút Sao chép source máy chủ dưới đây rồi dán toàn bộ vào editor. Đây là file gộp, không cần tạo thêm import/module trong editor.
  4. Bấm Deploy và chờ trạng thái sẵn sàng.
  5. Mở function → Details / Settings → tắt Verify JWT hoặc Enforce JWT verification, rồi lưu. Ứng dụng dùng phiên đăng nhập nội bộ, được xác thực trong source máy chủ.
  6. URL function phải là https://MA-PROJECT.supabase.co/functions/v1/trainer-hub.

Điền hai giá trị vào HTML và bật GitHub Pages

  1. Mở file index.html bằng VS Code, TextEdit ở chế độ văn bản thuần, hoặc Notepad.
  2. Tìm HUB_CONFIG gần đầu file. Điền hai giá trị công khai từ Supabase mới:
const HUB_CONFIG = {
  supabaseUrl: "https://MA-PROJECT.supabase.co",
  publishableKey: "PUBLISHABLE_KEY_CUA_PROJECT_MOI"
};
  1. Lưu file với tên chính xác index.html, mã hóa UTF-8. Không để thành index.html.txt.
  2. Mở repository GitHub mới → Add file → Upload files. Kéo index.html vào thư mục gốc. Có thể tải thêm terms.html, privacy.html để dùng cho các URL TikTok. Bấm Commit changes.
  3. Vào Settings → Pages. Chọn Deploy from a branch, branch main, folder / (root) → Save.
  4. Mở Actions, đợi workflow pages build and deployment màu xanh. Quay lại Pages → Visit site.
  5. Đối chiếu link Pages với APP_URL trong Supabase. Nếu khác, sửa Secret APP_URL cho khớp link thật.

Chỉ nhập Project URL và publishable/anon key vào HTML. Client Secret TikTok và mã khởi tạo Admin nằm trong Supabase Secrets.

06

Tạo Admin, khu vực, Trainer và user

  1. Mở link Pages. Lần đầu sẽ thấy Khởi tạo Admin. Nhập mã BOOTSTRAP_TOKEN đã đặt, tên hiển thị, username và mật khẩu ít nhất 10 ký tự. Bấm Tạo Admin đầu tiên.
  2. Ứng dụng tự đăng nhập. Các lần sau đăng nhập bằng username/mật khẩu vừa tạo. Có thể xóa BOOTSTRAP_TOKEN trong Secrets sau khi đã tạo Admin; hệ thống không cho khởi tạo lại khi đã có tài khoản.
  3. Vào Khu vực & Trainer → thêm các khu vực → thêm họ tên từng Trainer và gán khu vực. Dùng Sửa khi đổi tên/phân công để giữ đúng ID và lịch sử.
  4. Vào Tài khoản → nhập tên hiển thị, username, mật khẩu → chọn vai trò Trainer → chọn đúng Trainer → Tạo user. Mỗi Trainer gắn một tài khoản. Có thể tạo Admin phụ tại đây.
  5. Gửi link ứng dụng và thông tin đăng nhập riêng cho từng người theo cách của bạn. Trainer đăng nhập bằng tài khoản ứng dụng này.

Không tạo các user này ở Supabase → Authentication → Users. Bản độc lập sử dụng module tài khoản nội bộ, lưu trong bảng riêng và kiểm tra quyền ở Edge Function.

07

Thiết lập TikTok cho bản độc lập

Để hai hệ thống chạy đồng thời độc lập, nên dùng ứng dụng hoặc Sandbox có bộ Client Key/Secret riêng cho bản mới, thay vì tạo hai nơi refresh cùng một grant. Không chép token hoặc các bản ghi kết nối mã hóa từ Supabase cũ sang project mới.

7.1 — Tạo ứng dụng/Sandbox và quyền

  1. Người nhận đăng nhập tài khoản TikTok for Developers của họ, tạo ứng dụng hoặc Sandbox riêng cho Trainer Hub và dùng bộ Client Key/Secret của họ.
  2. Thêm Login Kit. Trong Scopes, thêm user.info.basic, user.info.profile, video.list, user.info.stats. Quyền stats dùng lấy follower.
  3. Ở Web / Website URL dùng link Pages mới. Nếu TikTok yêu cầu Terms / Privacy, điền link .../TrainerHub/terms.html và .../TrainerHub/privacy.html. Thay các chỗ [Tên đơn vị quản lý của bạn] và [Email liên hệ của bạn] trong hai trang bằng thông tin của người nhận trước khi dùng.
  4. Ở Login Kit → Web → Redirect URI, điền chính xác:
https://MA-PROJECT.supabase.co/functions/v1/trainer-hub/oauth/callback
  1. Trong Sandbox settings → Target users, thêm đúng tài khoản TikTok dùng thử, rồi Apply changes.
  2. Copy Client Key và Client Secret của Sandbox này vào TIKTOK_CLIENT_KEY, TIKTOK_CLIENT_SECRET trên Supabase mới.
  3. Nếu có 13 Trainer, dùng hai Sandbox của bản độc lập: tối đa 10 target user trong Sandbox chính và 3 người trong Sandbox thứ hai. Thêm bộ khóa thứ hai bằng hai Secret TIKTOK_SANDBOX2_CLIENT_KEY, TIKTOK_SANDBOX2_CLIENT_SECRET. Cả hai dùng cùng callback mới ở trên, nhưng mỗi Sandbox có bộ khóa và danh sách Target users riêng.

“Add up to 10 Redirect URIs” là tối đa 10 URL callback. Giới hạn số tài khoản thử nghiệm được quản lý riêng tại Target users. Production cho người dùng ngoài Target users cần TikTok phê duyệt.

7.2 — Nếu TikTok yêu cầu Verify URL

  1. Chọn URL prefix và nhập link gốc https://TEN-GITHUB.github.io/TrainerHub/.
  2. Tải file xác minh do TikTok cấp. Tải nguyên tên và nội dung file đó lên thư mục gốc repository mới, cùng cấp index.html.
  3. Chờ Pages triển khai. Mở URL .../TrainerHub/ten-file-tiktok.txt, kiểm tra nhìn thấy nội dung xác minh, rồi quay lại TikTok bấm Verify.

7.3 — Gán và kết nối từng kênh

  1. Admin vào Xây kênh → Quản lý kênh → Gán trang TikTok.
  2. Chọn Trainer, nhập https://www.tiktok.com/@tenkenh, chọn đúng Sandbox và ngày bắt đầu tính target. Lưu.
  3. Trainer đăng nhập ứng dụng → Quản lý kênh → Kết nối. Đăng nhập đúng tài khoản TikTok đã gán và đồng ý quyền. Để có số follower, bấm Cấp quyền follow nếu kết nối chưa có quyền stats.
  4. Bấm Đồng bộ TikTok. Admin có thể đồng bộ tất cả; Trainer đồng bộ khu vực của mình và xem số liệu đã lưu của toàn team.

Mốc Follow tháng 10/2026 được Admin nhập theo số thực tế ngày 01/10. Tháng sau dùng lần ghi nhận thực tế đầu tiên trong ngày 01 theo giờ Việt Nam. Nếu thiếu số lịch sử thì để trống; API không tự trả lại lịch sử chưa ghi nhận. Tự đồng bộ mỗi 15 phút chỉ hoạt động khi đang mở mục Xây kênh.

Checklist hoàn tất:

  • Đăng xuất/đăng nhập Admin được; tạo khu vực, Trainer và user được.
  • Trainer chỉ có hai tab Xây kênh/Tài khoản, xem toàn team nhưng không có nút tạo user hoặc gán kênh.
  • Trainer kết nối đúng kênh và quay lại link Pages mới; số liệu chỉ hiện khi API thực sự trả về.
  • Khóa tài khoản hoặc đổi mật khẩu làm phiên cũ mất quyền.
  • Không có URL project Supabase cũ hoặc dữ liệu Trainer thật được đóng gói sẵn trong bản xuất.

Bản xuất đã được kiểm thử bằng dữ liệu giả lập cho đăng nhập, phân quyền, tạo cấu hình/user, hai Sandbox, callback, đồng bộ và biểu đồ. Kết nối thực tế với Supabase/TikTok mới cần hoàn tất các bước cấu hình trong hướng dẫn này.
